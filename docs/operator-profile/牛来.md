# 牛来

**分支：**近卫/突进战士（联动角色）

**所属势力：**草原（本项目设定）

**定位：**近战物理输出、越障突进、范围爆发。

**状态：**已接入可玩原型；数值为当前原型环境下的首轮试玩建议。模型已接入待机、跑步、攻击和飞行骨骼动画；牛妈妈使用独立橙红毛色的放大牛来模型。

## 角色说明

来自草原的小牛，怀着好奇与勇气走入战场。遇到挡路的对手，他会低头顶过去；遇到挡路的墙，他会大喊“中国牛能飞”；遇到自己解决不了的麻烦，他还有最后的办法——“妈妈！”

角色原型参考动画电影《牛来》中的小牛及牛妈妈；上述战场描述、职业和全部技能均为本项目原创玩法，不作为原作剧情陈述。

来源：[百度百科《牛来》](https://baike.baidu.com/item/%E7%89%9B%E6%9D%A5/59676341)。

## 基础属性

以下距离使用 Unity 世界单位，时间使用秒。首轮原型按固定属性、三个技能同时可用设计。

| 属性 | 建议值 |
| --- | --- |
| 生命上限 | 1300 |
| 攻击力 | 80 |
| 防御力 | 25 |
| 普攻间隔 | 0.9 秒 |
| 普攻范围 | 2.0 |
| 移动速度 | 5.0 |
| 普攻类型 | 单体近战物理伤害 |
| 可攻击目标 | 敌方地面干员、小兵和建筑 |

## 特性

**小牛冲锋：**以近战普攻持续输出，依靠短距离飞行接近远程目标或撤离。飞行期间仍可被攻击，不获得无敌、免伤或不可选中效果。

首版不额外配置数值天赋，将强度集中在三个技能上。

## 技能

### 一技能：牛劲十足

**触发方式：**手动；**恢复方式：**自动冷却。

牛来低头蓄起牛劲，使 **5 秒内的下一次普攻造成攻击力 250% 的物理伤害**。命中时以强化伤害替代该次普攻伤害，仍只攻击一个目标。

| 属性 | 建议值 |
| --- | --- |
| 首次等待 | 0 秒 |
| 冷却时间 | 6 秒 |
| 强化保留时间 | 5 秒 |
| 总伤害倍率 | 250% 攻击力 |
| 基础属性下的总伤害 | 200（扣除防御前） |

激活时开始冷却；重复激活不能叠加。强化普攻沿用普通攻击间隔，不重置普攻计时。仅在攻击实际命中时消耗强化，攻击被取消时保留；过期、死亡或撤退时清除。可以攻击建筑，不附带眩晕、击退或范围伤害。

### 二技能：中国牛能飞

**触发方式：**手动选择地面位置；**恢复方式：**自动冷却。

牛来大喊“中国牛能飞！”，沿抛物线飞向指定位置，**最多位移 5.5 个单位，可越过途中障碍物和单位**。

| 属性 | 建议值 |
| --- | --- |
| 首次等待 | 0 秒 |
| 冷却时间 | 14 秒 |
| 最大位移距离 | 5.5 |
| 飞行时间 | 1.5 秒 |
| 表现用最高离地高度 | 2.0 |
| 技能伤害 | 0 |

飞行期间不能普攻或施放其他技能，一技能强化的剩余时间照常减少。飞行只绕过移动障碍，战斗判定仍使用地面单位身份，敌方普攻、投射物和防御塔可以继续命中。

落点必须位于场内可站立地面，不能落入障碍、建筑或其他单位的碰撞体。超出距离的指令截取至最大距离；无合法落点时拒绝施放且不进入冷却。起飞后开始冷却；若落点被新障碍占据，沿飞行路径回退到最近的合法地面。飞行期间死亡或撤退时立即终止，不能用飞行离开地图边界。

### 三技能：妈妈

**触发方式：**手动选择地面位置；**恢复方式：**自动冷却。

牛来大喊“妈妈！”，召唤牛妈妈从天而降。目标区域出现 **1.8 秒落地预警**，随后牛妈妈砸向地面，对半径 **2.8** 内的敌方地面单位造成 **攻击力 450% 的物理伤害**。

| 属性 | 建议值 |
| --- | --- |
| 首次等待 | 15 秒 |
| 冷却时间 | 36 秒 |
| 施法距离 | 7.0 |
| 落地预警 | 1.8 秒 |
| 伤害半径 | 2.8 |
| 总伤害倍率 | 450% 攻击力 |
| 基础属性下的伤害 | 每个目标 360（扣除防御前） |
| 对建筑伤害系数 | 50%（扣除防御前为 180） |

施法位置必须是场内合法地面，施法距离按平面距离判定；可隔着障碍指定位置。释放时锁定落点并开始冷却，落地时按目标实际位置判定命中，同一个单位只受伤一次。伤害不穿过实体障碍或建筑墙体；建筑本身可受伤，但不能借范围伤害命中其背后的单位。

牛妈妈为一次性技能表现，落地后消失，不产生持续作战的召唤单位。技能不伤害友军、不命中空中单位，不附带眩晕或减速。牛来释放后可继续移动和普攻；技能成功释放后，即使牛来死亡或撤退，已开始的落地效果仍会完成，伤害归属于牛来。

## 数值依据与玩法

当前场景构建代码中的能天使为 1000 生命、50 攻击，小羊为 950 生命、75 攻击，银灰为 1400 生命、85 攻击；防御值分别为 2、10、30。牛来以 1300 生命换取接近远程单位的容错，攻击力和近战射程低于银灰，越障位移不额外附带伤害。

伤害沿用当前物理结算规则：`最终伤害 = max(1, 攻击力 × 技能倍率 × 目标类型系数 - 目标防御)`，防御对每个目标扣除一次。一技能伤害是替代普攻的总量，不再额外叠加一次普通攻击。

| 目标 | 普攻 | 牛劲十足 | 妈妈 | 强化普攻 + 妈妈占目标生命上限 |
| --- | --- | --- | --- | --- |
| 能天使（1000 生命 / 2 防御） | 78 | 198 | 358 | 55.6% |
| 小羊（950 生命 / 10 防御） | 70 | 190 | 350 | 56.8% |
| 银灰（1400 生命 / 30 防御） | 50 | 170 | 330 | 35.7% |

推荐连招：提前开启“牛劲十足” → “中国牛能飞”越障进场 → 强化普攻 → 在敌人退路释放“妈妈”。飞行与大招不附带控制，敌人能利用射程压制、飞行时集火和落地预警进行反制。

以上比较采用未受增益的基础攻击力，只说明首轮数值尺度，尚不能证明平衡。接入后重点观察远程角色逃生率、大招多人命中率及越障追击成功率；若追击过强，优先加长飞行冷却或缩短距离，若大招过强，优先缩小半径或加长预警。

表现：W 强化期间显示金色脚下光环、环绕上升光条及身体发光，强化普攻消耗或到期后关闭。妈妈毛色为橙红，保留浅色嘴部及眼睛等细节。

E 完整动作已接入游戏：起飞蓄力、前扑飞行、转正下降、屈膝落地、恢复站立。动作与视觉高度及水平位移共用进度；全程 1.5 秒，落地缓冲结束后恢复普通指令。
